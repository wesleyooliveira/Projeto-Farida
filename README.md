# Farida Churrasqueiras

Landing page para a marca Farida Churrasqueiras, desenvolvida com HTML, CSS e JavaScript puros.

## Descrição

Este projeto é uma landing page institucional para apresentação de churrasqueiras em aço inox e galvanizado, com foco em conversão pelo WhatsApp e contato direto com a fábrica.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Estrutura do projeto

- `index.html` — estrutura da página
- `styles.css` — estilos e layout
- `script.js` — animações e comportamento leve

## Como visualizar localmente

1. Abra a pasta do projeto no navegador.
2. Ou execute um servidor local, por exemplo:

```bash
python -m http.server 8000
```

3. Acesse:

```text
http://localhost:8000
```
